# 0002: LLM Wikiの運用にリポジトリ固有スキルを使用する

- ステータス: Accepted
- 日付: 2026-07-24

## 背景

LLM Wikiの運用では、セッション開始時のコンテキスト読み込みと、作業の区切りやpush前の
Wiki更新を定型化する必要があります。これまで運用文書に記載していた `context-load` と
`update-doc` はexoloop由来であり、このリポジトリには含めない方針です。

外部由来の未管理スキルを前提にすると、別環境で同じ運用を再現できず、運用文書に書かれた
手順とリポジトリに含まれる実体が一致しません。

## 決定

セッション開始時のWiki読み込みには `load-wiki-as-context`、作業の区切りとpush前の
Wiki更新には `update-wiki` というリポジトリ固有スキルを使用します。

両スキルは後続作業で `config/.claude/skills/` に実装します。実装されるまでは、
`wiki/SCHEMA.md` の読み込み手順と更新規約を手動で適用します。

## 影響

- LLM Wikiの運用に必要なスキルと、その役割が名前から判別しやすくなります。
- スキル実装後はdotfilesを通じて環境間で同じ運用を再現できます。
- 実装完了までは、コンテキスト読み込みとWiki更新を手動で行う必要があります。
- `wiki-init` が生成する運用説明も、新しいスキル名を使用します。
