# raw/ — 記録層（事実の原本置き場）

ここは事実の原本を置く層。**追記のみ・書き換え禁止・削除禁止**。
過去の記録が間違っていた場合も本文は直さず、新しい記録を追記して訂正する。

## 場所と命名

| 場所 | 内容 | 命名 |
|---|---|---|
| `conversations/` | 作業セッション・調査・議論の記録 | `YYYY-MM-DD_トピック.md` |
| `decisions/` | 設計・運用上の決定の記録 | `NNNN-決定内容.md`（連番） |
| `issues/` | 問題・障害の記録（関連ファイルごと） | `YYYY-MM-DD_番号/` |

## 運用

- 新しい知見はまずここに原本として記録する
- ここを根拠（sources）にして `wiki/pages/` へ蒸留する
- wiki 側から raw を参照することはあっても、raw が wiki を参照することはない
